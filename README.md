# OverTheWireTut

My personal OverTheWire tutorial notes.

This repository documents how I solve OverTheWire levels, starting with the **Natas** web security wargame. The goal is not only to record the steps, but to explain the reasoning and web security concepts behind each level.

OverTheWire is a collection of security games used to practice Linux, web security, and general IT concepts in a legal training environment.

Natas focuses on web security, so these notes introduce ideas such as:

- HTML source code
- URL paths
- Directory listing
- `robots.txt`
- HTTP headers
- Cookies
- Sessions
- Access control mistakes

## Writeup Structure

Each solved level usually includes:

- What the level teaches
- Goal
- Login information
- Step-by-step walkthrough
- How the clue was identified
- Explanation of new terms
- Security lesson
- Key takeaways

The notes are written for someone learning IT and web security from the beginning, so important terms are explained when they first appear.
